## Delivered behavior

- `/copperback` toggles the saved preference for players with `blockback.copper`; both permission and preference default false. `/blockback` reports CopperBack status and its command.
- Enabled sneak + right-click with an axe advances one stage. Ordinary clicks, non-axes, missing permission and disabled preferences leave event results untouched, allowing vanilla scraping/unwaxing/statue revival.
- Fully oxidized and waxed recognized copper consume the enabled gesture without mutation or sound. Main-hand axes take priority; an offhand axe can operate when the main hand has no axe. A second axe event is consumed without a second conversion.
- A dedicated HIGHEST copper handler respects independent block-use and item-use DENY flags before mutation. It never uncancels another plugin's denial.
- Runtime discovery recognizes nine families on the cached baseline API and fifteen on cached 26.3, including irregular `COPPER_BLOCK` and `LIGHTNING_ROD` names. All available families are tested through explicit expected transitions, independently of discovery.
- Conversion substitutes only the material key and keeps the complete block-data property suffix. It prepares captured BlockState snapshots before writing, updates with force and no physics, reads back actual BlockData and rolls back attempted updates on failure.
- Doors and double copper chests are validated and converted together. Door half direction and both chest half directions in all four facings are asserted. An unloaded chest partner chunk is rejected without trying to load or access it.
- Tile conversion uses the captured snapshot containing opaque tile state. Fake replacement tests clear live tile data before reapplying the snapshot and check inventory/custom item data/name/lock/loot/PDC retention. This tests the intended API use; it does not prove real server inventories safe.
- Existing `sounds.yml` values are retained; missing `copperback` keys use defaults, newly generated files contain the section, and successful conversions alone trigger sound. Default sound is `ITEM_AXE_SCRAPE`.
